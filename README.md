# 굴착기 전복 예방 시뮬레이터 (CAT 320)

AX 챌린지 · AI콘텐츠공학 × 메카트로닉스공학과

굴착기(CAT 320)가 비탈길이나 경사진 지형에서 움직일 때 넘어질 위험이 얼마나 커지는지 3D 화면으로 미리 확인하는 교육용 웹 시뮬레이터입니다.

**바로 해 보기:** https://kuk97339429-source.github.io/heavy-equipment-rollover/
(QR: `presentation/images/qr_simulator.png` — 안전교육 시작 화면 `web/home.html`이 열리고, "학습 시작"으로 시뮬레이터, "진단 테스트"로 테스트에 들어갑니다)

> 2일 동안 만든 학습·시연용 근사 모델입니다. 지반 붕괴·침하, 미끄러짐 등은 반영하지 않으므로 실제 현장 안전 판단에 단독으로 쓰면 안 됩니다.

## 무엇을 하나요
- 굴착기를 5개 부분(버킷·암·붐·회전몸체·하부 주행체)으로 나눠 전체 무게중심을 계산합니다.
- 경사와 움직임(주행 가속도, 팔의 회전 관성)을 반영해 힘이 바닥에 작용하는 지점을 구합니다.
- 트랙이 실제로 땅에 닿는 영역(트랙마다 13개 접지 샘플)과 비교해 **안정 / 주의 / 전복 위험**을 실시간으로 표시합니다.
- 오르막 → 평지 → 내리막 지형(0~50°), 버킷 적재량(0~1,500 kg), 3인칭 / 1인칭(운전석) 시점을 지원합니다.

## 실행 방법
- 웹: 위 주소를 PC 브라우저로 열기 (인터넷 필요 — three.js를 CDN에서 받음)
- 로컬: 저장소를 받아 `web/index.html`을 브라우저로 열기
- 조작: Q/A 붐 · W/S 암 · E/D 버킷 · ←/→ 선회 · ↑/↓ 주행 · V 시점 · H 패널

## 사용한 값과 한계
- 운전중량 22,600 kg, 붐 5.7 m, 암 2.9 m, 롤러 중심거리 3.65 m, 궤간 2.38 m: CAT 320 공식 제원
- 부품별 질량·무게중심 위치, 관절 범위·속도: 팀 시트 값(일부 추정)
- '주의' 기준 0.35 m는 임시값
- 정적·준정적 모델: 짧은 충격, 지반 변형, 미끄러짐 미반영
