[프로젝트 요약] (2026-11-06 기준, 구현 상태 재확인)

■ 무엇을 만드는 프로젝트인가요?
CAT 320 굴착기의 자세와 경사 방향을 바꾸면서, 정지 상태에서 계산한 무게중심 투영점이 가정한 지지영역 안에 있는지 시각화하는 교육용 시뮬레이터입니다.

■ 현재 웹 시뮬레이터가 하는 일
- three.js 굴착기 3D 모델의 붐·암·버킷·선회와 주행을 조작
- 경사각과 경사 방향을 조절
- 다섯 부품의 질량 가중으로 합성 무게중심을 계산
- 중력 방향 투영점과 직사각형 지지영역 경계 사이의 최소 거리를 표시
- CAT 질량 설정과 팀 시트 질량 설정을 비교

■ 판정 결과를 어떻게 읽나요?
화면의 거리값은 '실제 전복까지 남은 안전거리'가 아닙니다. 고정된 직사각형 지지영역을 가정했을 때 투영점이 그 경계에서 얼마나 떨어져 있는지를 뜻합니다. 화면 상태도 '투영점이 지지영역 안/밖'으로 해석해야 합니다.

■ 질량과 데이터 출처
Cat 공식 페이지는 선택된 구성의 운전중량 22,600kg을 제시합니다. 웹 모델의 버킷 880kg, 암 1,300kg, 붐 2,050kg, 하부 7,760kg은 Cat 구성품 자료를 바탕으로 합니다. 회전몸체 10,610kg은 독립된 공식 부품 측정값이 아니라 총중량에 합계를 맞춘 잔여값입니다. 부품별 무게중심 위치와 모델 형상은 별도 실측 검증이 필요합니다.

■ 현재 모델의 한계
- 정적 계산입니다. 주행·급정지·급선회·굴삭 반력에 따른 관성을 판정에 넣지 않습니다.
- 현재 지지영역은 롤러 중심거리와 트랙 중심간격으로 만든 직사각형 근사입니다. 요철, 실제 접지 상태, 트랙 변형 및 지반 침하를 계산하지 않습니다.
- 버킷 적재물은 현재 웹 계산에 포함되지 않습니다.
- 미끄러짐, 토양 붕괴, 유압 한계, 구조물 변형을 계산하지 않습니다.
- CAT 인양표는 평지 인양 조건 비교 자료입니다. 그것만으로 경사지 전복 예측을 검증했다고 볼 수 없습니다. 현재 문서에 적힌 비교 오차는 사전 계산이며 완료된 홀드아웃 검증 결과가 아닙니다.
- 화면에서 '안정/주의' 임계값으로 쓰던 0.35m는 실증 근거가 확인되지 않아 상태 판정에서 제거했습니다.

■ 사용 시 주의
교육·시연용 프로토타입입니다. 실제 장비 운용, 작업허가, 현장 위험성 평가나 안전 판정에 사용하지 마세요. 현재 결과는 모델 가정에 따른 기하학적 표시이며 실제 사고 확률이나 안전 보증이 아닙니다.

■ 다음 우선 작업
1. 각 구성품의 무게중심 좌표와 회전몸체 후방 오프셋을 출처·근거와 함께 확정
2. 지지영역/전복축 가정을 CAT 인양표 계산 조건과 대조하고 기록
3. 평지 인양표 보정 데이터와 독립 평가 데이터를 분리해 오차표 공개
4. 적재물과 요철·접지 모델은 입력 자료와 검증 방법을 먼저 정한 뒤 추가
5. 동역학·지반 거동은 별도 검증 전까지 범위 밖으로 명시

■ 코드 안내
기본 시뮬레이터는 web/index.html입니다. app.py와 physics.py는 이전 Streamlit 프로토타입이며 현재 웹 구현의 기능·검증 상태를 대변하지 않습니다.
