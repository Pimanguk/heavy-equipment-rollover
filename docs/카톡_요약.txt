[우리 프로젝트 한눈에 보기] (11/6 최신)

■ 뭘 만드나요?
포크레인(CAT 320)이 비탈길에서 일할 때
"넘어질까, 안 넘어질까?"를
일하기 전에 미리 컴퓨터로 알려주는 서비스예요.

■ 오늘 바뀐 것 ★
1. 팀원이 만든 3D 웹 시뮬레이터를 우리 본 제품으로 정했어요.
   - 진짜 포크레인 모양 3D 모델(블렌더로 제작)
   - 붐·암·버킷·몸통 회전을 실제 속도 제한대로 움직임
   - 전진·후진 주행 가능
   - 넘어지기까지 남은 여유를 실시간으로 보여줌
   → 예전에 만든 간단한 화면(Streamlit)은 쓰지 않아요.
2. 부품 무게는 CAT 공식 자료 값으로 정했어요.
   버킷 880kg / 암 1,300kg / 붐 2,050kg
   회전몸체 10,610kg / 하부(무한궤도) 7,760kg
   → 합계 22,600kg (CAT 공식 홈페이지 값과 같음)
   ※ 처음 시트 값과 비교해 보니,
     팔을 옆으로 길게 뻗을 때 "넘어지기 직전"과 "여유 있음"으로
     결과가 크게 달라졌어요. 그래서 공식 값으로 통일했어요.
3. 3D 화면은 three.js 방식으로 확정!

■ 왜 필요한가요?
- 공사 현장 장비 사고로 숨지는 사람 중 포크레인이 가장 많아요.
  (2016~2020년 104명, 1년에 약 20명)
- 2024년 포항에서 비탈에 짐을 내리던 포크레인이 넘어져
  사람이 숨진 사고가 있었어요.
- 법에는 "일하기 전에 작업계획서를 써라"는 규칙이 있지만
  무한궤도 포크레인이 몇 도까지 버티는지는 정해진 숫자가 없어요.
  → 우리 서비스가 그 빈칸을 도와줘요.

■ 어떻게 판단하나요?
1. 포크레인을 5조각으로 나눠요.
   버킷(삽) / 암(팔 끝) / 붐(큰 팔) / 회전몸체(운전석·엔진·뒷무게추) / 하부(무한궤도)
2. 각 조각의 무게와 위치로 "전체 무게중심"을 계산해요.
3. 무게중심이 트랙이 땅에 닿는 영역 안에 있으면 "안전",
   밖으로 나가면 "넘어짐"!
   (책상 위 컵이 바닥면 밖으로 기울면 쓰러지는 것과 같아요)

■ 시뮬레이터에 새로 붙인 것 (완료!)
- 비탈길 (기울기·방향 조절)
- 운전석 시점(1인칭) / 밖에서 보는 시점(3인칭) 바꾸기 (V키)
- 뒤쪽 2D 배경 그림 (하늘·산·타워크레인)
- 공식 무게 / 처음 시트 무게 비교 선택
- 계산이 맞는지 스스로 검사하는 기능 (공식 정답과 비교해서 모두 통과)
- "연습용 모델" 안내 문구
※ 예: 옆으로 20도 기운 비탈에서 초기 자세 → 여유 0.44m "안정"

■ 다음에 할 것
- 울퉁불퉁한 땅 + 트랙이 땅에 닿는 6점 계산
- 버킷에 담은 흙 무게
- 회전몸체 무게중심을 뒤쪽(뒷무게추 쪽)으로 옮기기
  (지금은 부품 상자의 가운데로 계산하고 있어요)
- CAT 공식 "들 수 있는 무게 표"와 비교해서 정확도 확인
- 인터넷 없어도 화면이 뜨게 만들기 (발표장 대비)

■ 계산에서 뺀 것 (2일 안에 하기 어려워서)
미끄러짐, 땅 꺼짐, 흙 무너짐, 바람, 유압 장치 속사정, 쇠가 휘는 것

■ 정확한지 어떻게 확인하나요?
CAT은 "이 거리에서 이만큼까지 들 수 있다"는 표를 공개해요.
이 표는 넘어지기 직전 무게의 75%로 만든 거라서
우리 계산과 비교하면 얼마나 맞는지 % 로 보여줄 수 있어요.
- 표의 일부로 값을 맞추고, 나머지로 시험해요. (커닝 방지)
- 목표: 차이 10% 이하

■ AI는 어디에 쓰나요?
- 넘어질지 판단하는 건 AI가 아니라 물리 공식으로 해요. (더 정확해서)
- AI는 결과를 보고 작업계획서에 쓸 안전 문장을 만들어 줘요.
- AI가 숫자를 틀리게 쓰면 그 문장은 버려요.
