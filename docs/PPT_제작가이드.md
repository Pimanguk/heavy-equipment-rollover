## 3. 넣을 영상 — 추천

### 결론: 「몸통 돌리기」 20초 영상 1개가 핵심, 시간이 되면 4개 클립을 이어 60~80초

| 순서 | 클립 | 길이 | 찍는 방법 | 보여줄 메시지 |
|---|---|---|---|---|
| ★1 | **방향 하나로 바뀌는 판정** | 20초 | 오르막 25° 위에서 붐 60°·암 30°·버킷 45°로 팔을 든 채, 선회를 0° → 180°로 천천히 돌림 (← → 키) | 여유가 +0.95 m(안정) → 주의 → −0.16 m(전복 위험)으로 떨어지고, 바닥 화살표가 지지영역 밖으로 빨갛게 나감 |
| 2 | 오르막 진입 | 15초 | 평지에서 오르막(15~18°)으로 전진(↑ 키). 오른쪽 패널의 '차체 기울기'와 '접지 샘플'이 변하는 순간 | 땅에 닿는 점이 바뀌면 지지영역도 다시 계산된다 |
| 3 | 짐을 늘리면 | 10~15초 | 평지, 팔을 옆으로 뻗은 자세(붐 0°, 암 −60°, 선회 90°)에서 버킷 적재량 0 → 1,500 kg | 여유 +0.50 m(안정) → +0.29 m(주의) |
| 4 | 급하게 멈추면 | 15초 | 평지, 적재 1,500 kg, 팔을 앞으로 높이 든 채(붐 60°, 암 30°) 최고속도로 전진하다 ↑ 키를 떼서 정지 | 정지 순간 맨 위 '유효' 여유가 0.87 m → 0.53 m로 줄어듦 — 움직이면 더 위험 (급선회는 차이가 작아 비추천) |
| 5 | 운전석 시점 | 10초 | V 키로 1인칭 전환, 마우스로 둘러보기 (오르막 위) | 운전석에서는 기울기가 잘 안 느껴진다 |

### 녹화 방법
- 화면: 브라우저 전체 화면(F11), 확대 100%, 1920×1080 · 30fps
- 도구: Windows `Win + Alt + R`(Xbox Game Bar) 또는 OBS
- 패널: 위쪽 「조작창」 버튼으로 왼쪽 패널을 숨기고, 숫자가 보이도록 **오른쪽 「분석창」은 켜 둔다** (H 키는 둘 다 숨김)
- 조작: 키보드로 천천히. 각 클립 끝에 판정 배지(안정/주의/전복 위험)가 보이는 상태로 2~3초 멈춤
- 소리: 넣지 않음. 편집 때 자막만 (예: "25° · 내리막 방향 → 전복 위험")
- 발표장 인터넷이 불안하면 라이브 데모 대신 이 영상을 튼다
