## 3. 신뢰성 설계 — 이 서비스의 핵심

### 3.1 데이터: 무엇이 공식이고 무엇이 추정인가

| 항목 | 값 | 태그 |
|---|---|---|
| 붐(+실린더) / 암 / 버킷 / 하부 주행체 질량 | 2,050 / 1,300 / 880 / 7,760 kg | **[공식]** Cat 사양서 Major Component Weights |
| 상부 회전체(카운터웨이트 4.2 t 포함) | 10,720 kg | [공식] 표에서 뺄셈 |
| 붐·암 길이, 버킷 팁 반경 | 5.7 / 2.9 / 1.57 m | **[공식]** |
| 롤러 중심거리 / 궤간 / 슈 폭 | 3.650 / 2.380 / 0.790 m | **[공식]** |
| 인양 능력표(전방·측방, 반경×높이) | ISO 10567:2007, 별표 없는 칸 = 전복 하중의 75% | **[공식]** |
| 링크별 무게중심 비율, 붐 풋 위치, 상부 무게중심 위치 | 0.45 / 0.35 / 0.40, (0.15, 1.95) m, x ≈ −1.45 m | [추정] → 보정 노브 |
| 요철 → 국부 기울기 표준편차 | E급 기준 앞뒤 0.85° / 좌우 1.06° | [추정] ISO 8608 노면 PSD에서 해석 유도 |

→ **질량은 전부 공식값**, 위치(무게중심 비율)만 추정. 추정값은 모두 노브로 노출하고 화면에 태그 표시.

### 3.2 검증(Verification) — 코드가 식을 맞게 푸는가
해석해 테스트 14개(`physics_validation.md` §5.1). 예: 무부하 옆경사 한계 = atan((B/2)/h), 중력선 연직, 대칭성, 질량 0 극한.

### 3.3 확인(Validation) — 식이 현실과 맞는가
1. 각 칸 (반경 R, 높이 h)에 암 끝이 오도록 역기구학으로 자세를 푼다.
2. 모델 정격 S = 0.75 × 전복 하중, 공식값 D와 비교: E = (S − D)/D
3. 별표 칸(유압 한계)은 S ≥ D 단측 검사만.
4. **보정은 반경 6.0 m 열로만, 평가는 7.5 m·최대 반경 칸으로(홀드아웃).**
5. 목표: 보정 후 홀드아웃 |E| ≤ 10%, 발표 문구 ±15%. 보정 전 오차도 함께 공개.

사전 계산(보정 전): 정면 −8~−11%, 측면 −17~−21%. **한쪽(보수적)으로 일정**하고 칸 사이 산포가 작음 → 모델 형태는 맞고 상수만 어긋남. 유효 전복선 2개로 흡수 가능.

### 3.4 불확실성(몬테카를로)
입력: 경사 측정 σ 0.5°, 방향 σ 5°, 요철(ISO 8608 등급), 질량 σ 3%, 무게중심 위치 σ 0.10 m, 적재 하중 σ 10%.
출력: 전복 비율 + 안정 여유 분위수 + 표준오차. **"실제 사고 확률"이 아니라 "입력 불확실성 아래 전복 조건 비율"**이라고 표기.

### 3.5 발표 때 먼저 말할 한계
정적 모델(선회·급정지 동역학 제외) · 경사 거동은 실측 아닌 해석 검증 · 무게중심 위치는 추정 후 보정 · 요철은 도로 표준 차용 · 미끄러짐·침하 제외(실제 사고에서 비중 큼) · ISO 원문 미열람(사양서 각주로 확인).

## 4. 매니저 검토: 팀원 산출물 사이의 충돌과 정리

| 충돌 | 내용 | 정리 |
|---|---|---|
| ① 순환 논리 | 데이터 담당이 상부 무게중심(−1.45 m)을 인양표 **여러 열**로 역산 → 같은 표로 검증하면 순환 | 역산은 **6.0 m 열만** 다시 하고, 7.5 m·최대 반경은 평가 전용(물리 담당 절차 채택) |

| ③ 미끄러짐 코드 | 현재 `physics.py`·`app.py`에 μ, `GROUND`, `p_slide`가 남아 판정에 섞임 | **1일차 첫 작업으로 삭제**(제외 범위) |

AI를 **쓰지 않는 곳도** 명시: 전복 판정·최적 자세 탐색은 물리식(격자 탐색)이며 AI라고 부르지 않는다.

### 팀원 정리표(2026-11-06) 반영
- 채택: 트랙별 앞·중·뒤 6점 접지 → 실제 접지 다각형(평면 근사 한계 해소), 단위 규칙(SI 계산, 화면 °·km/h), 제외 범위 구체화(토양 붕괴·유압 상세·유연체·바람 추가), "실제 안전 판정 단독 사용 금지" 명시.
- 남은 결정: **포지션**(사전 검토·교육용 보조 도구 + 면책 문구 추천), **주행 관성**(차체 주행·km/h를 의미 있게 하려면 가감속·선회 관성을 합력에 포함 — D2와 같은 결정).

## 6. 시스템 구조

```
입력(UI) ─► kinematics.py   자세 4각 → 5개 구성요소 무게중심 위치
         ─► terrain.py      경사 + 요철 높이맵(시드 고정) → 트랙 접지면 최소제곱 평면 → 국부 경사
         ─► physics.py      합성 무게중심 · 4개 전복선 · 안정 여유 · 몬테카를로 · 인양표 확인
                ▼  result dict (팀 간 유일한 계약)
         ─► render (three.js, static/) 2D 배경판 + 3D 장비·지형 + 1인칭/3인칭
         ─► app.py          Streamlit UI · 위험 지도 · 검증 표 · LLM 계획서 문구
```
모듈별 함수 시그니처·자체 검사 항목: `design/architecture.md` §2, §4.
