## 3. 3장 「무엇을, 왜 만드나요」 본문

제목: 무엇을, 왜 만드나요

- 포크레인(CAT 320)이 비탈길이나 경사진 지형에서 움직일 때 넘어질 위험이 얼마나 커지는지 3D 화면으로 미리 확인하는 서비스입니다.
- 공사 현장 장비 사고로 숨지는 사람 중 포크레인이 가장 많습니다. (2016~2020년 104명, 1년에 약 20명)
- 실제 장비로 위험한 상황을 시험하기는 어렵습니다.
- 같은 경사에서도 팔의 자세, 적재량, 움직임에 따라 위험이 달라집니다.

→ 여러 조건을 직접 바꿔 보며 전복 위험을 쉽게 이해하도록 돕는 교육용 웹 시뮬레이터를 만들었습니다.

## 4. 4장 「AI툴 소개」 로고 아래 추가 문구

AI는 어디에 쓰나요
- 전복 위험은 물리 공식으로 계산합니다.
- AI는 계산 결과를 쉽게 설명하고 작업 시 주의사항을 정리합니다.
- AI가 쓴 숫자가 실제 계산 결과와 일치하는지 확인합니다.

## 5. 8장 「위험 단계 표시 방법」 제목 아래 추가 한 줄

어떻게 판단하나요: 5개 부분(버킷·암·붐·회전몸체·하부)의 무게중심 → 경사·움직임을 반영한 '힘이 바닥에 작용하는 지점' → 트랙이 땅에 닿는 영역과 비교. 가장자리에 가까울수록 위험, 밖으로 나가면 전복 위험.

## 6. 새 장 문구

### 10장 「정확한지 어떻게 확인하나요」
- 평지·비탈길·언덕·구덩이에서 결과를 비교합니다.
- 팔을 뻗거나 짐을 늘렸을 때 위험이 어떻게 달라지는지 확인합니다.
- 가속하거나 급정지할 때의 위험 변화도 확인합니다.
