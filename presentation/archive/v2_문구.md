## 01 문제 찾기

## 3. 아이디어를 점수로 골랐습니다 ★

- **제목**: 아이디어 20개, 심사 기준으로 점수화
- **화면 문구**:
  - 두 전공 키워드(기계·로봇 + AI 콘텐츠)로 후보 20개 도출
  - 심사 기준 6개 × 5점 = 30점 만점으로 비교
  - 하드웨어 없이 2일 안에 완성할 수 있는지도 함께 따짐
  - 최종 선택: 중장비 전복 위험 판정 서비스 (28점)
- **시각 자료**: 점수 상위 5개 막대그래프(1위 강조)
- **발표자 노트**: 처음에는 두 전공에서 나온 키워드로 아이디어를 스무 개 정도 뽑았습니다. 그리고 심사 기준 여섯 개를 5점씩, 30점 만점으로 매겨 비교했습니다. 하드웨어가 없다는 조건도 반영했습니다. 그 결과 중장비 전복 위험 판정이 28점으로 가장 높았습니다.

## 4. 이미 있는 서비스인지 확인했습니다

- **제목**: 비슷한 서비스는 '넘어진 뒤'에 반응한다
- **화면 문구**:
  - 장비 내장 기울기 경보: 기울어진 다음에 울림
  - 플릿 관리 소프트웨어·특허: 감시와 기록 중심
  - 작업 '전'에 전복 위험을 시뮬레이션하는 서비스는 찾지 못함
- **시각 자료**: 비교표(기존 = 사후 경보 / 우리 = 사전 예측)
- **발표자 노트**: 같은 서비스가 이미 있으면 의미가 없어서 먼저 찾아봤습니다. 기존 제품은 대부분 장비가 기울어진 다음에 경보를 울리는 방식이었습니다. 작업 전에 미리 위험을 계산해 주는 서비스는 찾지 못했고 그 빈자리를 목표로 잡았습니다.

## 5. 왜 이 문제인가 ★

- **제목**: 굴착기는 건설기계 사망사고 1위
- **화면 문구**:
  - 21.6% — 건설기계 사망사고 중 굴착기 비중 (2016~2020년)
  - 104명 — 같은 기간 사망자, 한 해 약 20명
  - 2024년 포항: 경사지에 짐을 내려놓던 굴착기가 넘어져 작업자 사망, 대표와 기사 모두 처벌 확정
  - 출처: 고용노동부 분석 인용 보도, 판결 보도
- **시각 자료**: 큰 숫자 두 개 + 사고 사례 카드
- **발표자 노트**: 굴착기는 건설기계 사망사고에서 가장 큰 비중을 차지합니다. 5년 동안 104명, 한 해에 스무 명꼴입니다. 2024년 포항에서는 비탈에 짐을 내려놓던 굴착기가 넘어져 사람이 숨졌고 기사까지 처벌을 받았습니다.

## 6. 문제를 한 문장으로 정의했습니다 ★

- **제목**: 법은 있는데, 기준 숫자는 없다
- **화면 문구**:
  - 법: 산업안전보건기준에 관한 규칙 제38조 — 작업 전 사전조사·작업계획서 작성 의무
  - 숫자: 무한궤도 굴착기가 몇 도까지 버티는지 정한 기준 없음 (타이어식만 좌우 25°)
  - 문제 정의: "작업계획서를 쓰는 사람이 경사지 전복 위험을 숫자로 확인할 방법이 없다"
- **시각 자료**: 좌우 대비 카드(있다 / 없다) + 아래 문제 정의 강조 박스
- **발표자 노트**: 법은 작업 전에 계획서를 쓰라고 합니다. 그런데 무한궤도 굴착기가 몇 도까지 버티는지는 정해진 숫자가 없습니다. 그래서 문제를 이렇게 정의했습니다. 작업계획서를 쓰는 사람이 전복 위험을 숫자로 확인할 방법이 없다는 것입니다.

## 02 자료 조사·기획

## 7. 근거는 공식 자료에서 ★

- **제목**: 숫자는 공식 자료에서 가져왔습니다
- **화면 문구**:
  - CAT 공식 홈페이지: 선택된 구성의 운전중량 22,600 kg
  - CAT 사양서: 구성품 질량·치수 (회전몸체 질량은 잔여값으로 추정)
  - CAT 인양 능력표: 평지 인양 정격 비교 자료 (경사지 검증 자료는 아님)
  - 국가법령정보센터: 작업계획서 의무, 전도 안정 기준 확인
- **시각 자료**: 출처 아이콘 4개(홈페이지·사양서·표·법령)
- **발표자 노트**: 총 운전중량과 일부 구성품 질량·치수는 Cat 자료를 참고했습니다. 회전몸체 질량과 부품별 무게중심은 공식 개별 측정값이 아니라 추정 또는 잔여값입니다. Cat 인양 능력표는 평지 인양 조건의 참고 비교 자료이며, 경사지 전복 정확도를 입증하지 않습니다.

## 8. 공식과 추정을 나눴습니다

- **제목**: 무엇이 공식 값이고 무엇이 추정인가
- **화면 문구** (표):
  - 운전중량 22,600 kg — CAT 공식 홈페이지
  - 일부 구성품 질량은 CAT 자료, 회전몸체 질량은 잔여 추정값
  - 붐·암 길이, 트랙 치수 — CAT 공식 사양서
  - 부품 안 무게중심 위치 — 추정 (보정 예정)
  - 관절 범위·속도 — 팀 측정 시트 (추정)
- **시각 자료**: 표, 추정 칸만 다른 색
- **발표자 노트**: 숫자의 출처를 공식과 추정으로 나눠 표시했습니다. 부품 안에서 무게가 정확히 어디 있는지는 공개 자료가 없어서 추정했습니다. 그 값은 나중에 고칠 수 있게 따로 빼 두었습니다.

## 9. 만들 범위를 먼저 정했습니다

- **제목**: 무엇을 넣고 무엇을 뺄지
- **화면 문구**:
  - 반드시: 부품 5개 무게중심(버킷·암·붐·회전몸체·하부), 2D 배경 + 1인칭/3인칭 화면
  - 바꿔 볼 값: 경사각과 방향, 비포장 지형, 무게
  - 뺀 것: 미끄러짐, 지반 침하, 흙 무너짐, 바람, 유압 세부, 쇠의 변형
- **시각 자료**: 3열 카드(반드시 / 변수 / 제외)
- **발표자 노트**: 2일 안에 끝내려면 범위를 먼저 정해야 했습니다. 무게중심은 다섯 부품으로 계산하고 화면은 운전석과 바깥 시점을 모두 보여주기로 했습니다. 미끄러짐이나 지반 침하처럼 2일 안에 제대로 다루기 어려운 것은 과감히 뺐습니다.

## 10. 팀원 시뮬레이터로 방향을 바꿨습니다

- **제목**: 더 나은 결과물을 기준으로 따라갔습니다
- **화면 문구**:
  - 처음: 간단한 웹 화면 + 상자 모양 3D
  - 팀원 결과물: Blender 실제 굴착기 모델 + three.js 웹 시뮬레이터
  - 관절이 실제 속도·가속도 제한대로 움직이고, 주행도 가능
  - → 팀원 결과물을 본 제품으로 정하고 기능을 덧붙임
- **시각 자료**: 전(상자 3D) / 후(실제 모델) 비교 화면
- **발표자 노트**: 처음에는 상자 모양으로 굴착기를 그렸습니다. 그런데 팀원이 블렌더로 실제 굴착기 모델과 웹 시뮬레이터를 만들어 왔는데 훨씬 완성도가 높았습니다. 그래서 팀원 결과물을 기준으로 삼고 그 위에 경사면과 시점 전환 기능을 붙였습니다.

## 03 AI 활용 방법

## 11. AI를 팀처럼 나눠 썼습니다 ★

- **제목**: AI 팀원 4명에게 조사를 나눠 맡겼습니다
- **화면 문구**:
  - 매니저 AI: 결과를 모으고 서로 다른 내용을 정리
  - 물리·검증 담당: 무게중심 식, 검증 방법, 표준·법규
  - 제원·데이터 담당: CAT 320 무게표, 인양 능력표, 사고 통계
  - 시각화 담당: 3D 화면 구조, 1인칭/3인칭 구현
  - 서비스 기획 담당: 사용자, 심사 기준 대응, 데모 시나리오
- **시각 자료**: 조직도(매니저 1 → 담당 4)
- **발표자 노트**: AI를 한 번에 하나씩 쓰지 않고 역할을 나눈 팀처럼 썼습니다. 네 명의 AI 담당이 동시에 조사하고, 매니저 AI가 결과를 모아 서로 맞지 않는 부분을 정리했습니다. 공통 규칙은 모든 숫자에 출처를 달고 확인 못 한 것은 미확인으로 적는 것이었습니다.

## 12. AI가 한 일, 사람이 한 일

- **제목**: 결정은 사람이, 반복 작업은 AI가
- **화면 문구**:
  - AI: 자료 검색과 출처 정리, 시뮬레이터 기능 구현과 자체 검사, 문서·발표 문장 다듬기
  - 사람: 주제 선택, 기준 장비와 질량표 결정, 결과 확인과 최종 판단
- **시각 자료**: 좌우 2열(AI / 사람) 아이콘
- **발표자 노트**: AI는 자료를 찾고 코드를 만들고 문서를 정리하는 일을 맡았습니다. 어떤 주제를 할지, 어떤 장비와 어떤 무게 자료를 쓸지 같은 결정은 저희가 했습니다. AI가 낸 결과도 저희가 화면으로 직접 확인했습니다.

## 13. AI를 쓰지 않은 곳 ★

- **제목**: 판정은 AI가 아니라 물리식으로
- **화면 문구**:
  - 쓰지 않음: 전복 판정, 안전 자세 찾기 → 물리 공식이 더 정확
  - 향후 계획: 판정 결과를 작업계획서·TBM 문장 초안으로 바꾸기 (웹에 미구현)
  - 숫자 검증 절차를 구현·확인하기 전까지 AI 문장은 사용하지 않음
- **시각 자료**: ✕ / ✓ 두 카드
- **발표자 노트**: 현재 웹은 AI 문장 생성 기능을 제공하지 않습니다. 향후 문장 초안 기능을 추가한다면 계산 결과를 그대로 반영하는 검증 절차를 먼저 구현해야 합니다. 전복 여부는 현재 단순 정적 기하 모델이 계산하지만, 그 결과가 현장 안전을 보증하지는 않습니다.

## 04 결과 검토·수정

## 14. 결과물 ★

- **제목**: CAT 320 경사지 전복 위험 시뮬레이터
- **화면 문구**:
  - 3인칭: 자세·경사를 바꾸면 모델상 투영점과 지지영역 경계 간 거리가 바뀜
  - 1인칭: 운전석에서는 기울기가 잘 느껴지지 않음
  - 경사각 0~35°, 오르막 방향 0~180°
  - 바로 해 보기: kuk97339429-source.github.io/heavy-equipment-rollover
- **시각 자료**: 3인칭·1인칭 화면 2장 + QR 코드(링크)
- **발표자 노트**: 팔 자세와 경사를 바꾸면 가정한 지지영역 경계까지의 모델상 거리가 바뀝니다. 이 거리는 실제 전복까지의 안전 여유가 아닙니다. 운전석 시점과 외부 시점으로 형상과 기울기를 살펴볼 수 있습니다.

## 15. 검토하며 찾은 문제와 수정 ★

- **제목**: 검토로 찾은 문제, 이렇게 고쳤습니다
- **화면 문구**:
  - 부품 질량 배분 차이: 합계가 같아도 모델상 경계 거리 결과가 달라짐 → CAT 자료 기반 질량을 기본값으로 선택 (회전몸체 질량은 잔여값)
  - 순환 논리: 검증에 쓸 표로 값을 맞추고 있었음 → 맞추는 칸과 평가하는 칸을 분리
  - 1인칭 화면이 검게 가려짐: 카메라가 운전석 상자 안에 있었음 → 위치 수정
- **시각 자료**: 문제 → 원인 → 수정 3단 표 (거리값을 쓸 경우 '모델상 투영점 경계 거리'로 표기)
- **발표자 노트**: 부품 질량 배분에 따라 모델상 투영점 경계 거리가 달라지는 것을 확인했습니다. 이 값은 실제 안전 여유가 아니라 현재 지지영역 가정 아래의 계산 결과입니다. 회전몸체 질량도 독립된 공식값이 아니므로 모든 값을 CAT 공식 자료로 통일했다고 표현하지 않습니다.

## 16. 얼마나 맞는지 확인 ★

- **제목**: 정확도는 숫자로 확인합니다
- **화면 문구**:
  - 자체검사: 이상화한 기하 조건에서 투영 계산이 예상값과 맞는지 확인
  - 현실 검증: 아직 완료되지 않음
  - CAT 인양표는 평지 인양 조건 자료이며 경사지 검증에는 별도 실측이 필요
- **시각 자료**: 자체검사 완료 / 현실 검증 미완료 구분
- **발표자 노트**: 자체검사는 구현한 투영 계산이 이상화된 조건에서 기대한 결과와 맞는지 확인합니다. 이것은 실제 장비의 경사지 전복 성능 검증과 다릅니다. Cat 인양표는 평지 인양 정격 비교에 쓸 수 있지만, 경사지 검증은 실측이나 별도 자료가 없어 완료되지 않았습니다. 문서의 사전 오차 추정치를 검증 완료 결과처럼 제시하지 않습니다.

## 17. 한계와 다음 단계 ★

- **제목**: 한계를 알고, 다음 단계로
- **화면 문구**:
  - 한계: 직사각형 지지영역 근사, 적재물·요철·미끄러짐·지반 침하·동역학 미반영
  - 교육·시연용 프로토타입이며 실제 작업 안전 판정에 사용하지 않음
  - 다음: 무게중심·지지영역 가정 정리, 평지 인양표 비교와 독립 평가, 이후 적재물·요철 모델 검증
  - 감사합니다
- **시각 자료**: 좌우 2열(한계 / 다음 단계) + 링크
- **발표자 노트**: 이 도구는 고정된 직사각형 지지영역과 부품 무게중심 가정을 쓰는 교육용 프로토타입입니다. 적재물, 요철, 미끄러짐, 지반 침하와 주행·작업 관성을 계산하지 않습니다. 실제 현장 안전 판단에는 사용하지 않습니다. 다음 단계는 가정과 질량 자료를 정리하고, 평지 인양표 비교와 독립 평가를 수행하는 것입니다.
