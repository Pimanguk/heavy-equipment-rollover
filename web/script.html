Q&A 빠른 답변

실제 장비로 검증? 실측은 아직. CAT 인양 능력표(ISO 10567, 전복 하중의 75%)와 비교하는 방식으로 확인할 계획.

0.35 m 기준? 임시값. 화면에도 임시라고 표시. 인양 능력표 비교·현장 의견으로 다시 정함.

왜 AI로 판정 안 함? 물리 법칙으로 계산 가능. AI는 같은 입력에 같은 답 보장이 약하고 이유 설명이 어려움.

부품 무게 출처? 총 22,600 kg·붐 5.7 m·암 2.9 m는 CAT 공식. 부품별 무게는 팀 추정값 → 공식 무게표로 맞추는 게 향후 과제.

왜 CAT 320? 20톤급 대표 기종 + 제원·무게표·인양 능력표가 공식 사양서에 공개돼 숫자 확인 가능. ("가장 많이 팔린"은 말하지 않기)

현장에서 써도 되나? 안 됨. 2일 제작 교육용 근사 모델. 지반 침하·미끄러짐 미반영.
